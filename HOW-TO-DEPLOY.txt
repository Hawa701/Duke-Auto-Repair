DUKE AUTO REPAIR - HOW TO DEPLOY THE WEBSITE
=============================================

You need: out.zip (the complete website). Nothing else.
No database, Node.js, PHP or server settings are needed.

SiteGround: Site Tools > Site > File Manager

1. BACK UP (optional but recommended)
   In public_html, select everything and download it, or
   compress it to a zip, in case you need to roll back.

2. DELETE THE OLD SITE
   Open public_html. Turn on "Show hidden files" so .htaccess
   is visible. Select ALL files and folders in public_html and
   delete them.

3. UPLOAD THE NEW SITE
   Upload out.zip into public_html, right-click it > Extract.
   Then delete out.zip.

   Check: public_html/index.html must exist directly inside
   public_html (not public_html/out/index.html). If the files
   landed in a sub-folder, move its contents up into public_html.

4. CLEAR THE CACHE
   Site Tools > Speed > Caching > Flush Cache.

5. QUICK CHECK (in a private/incognito browser window)
   - The home page loads with images.
   - The Services and Vehicles We Service menus open.
   - /brake-repair/ and /toyota-mechanic/ load directly.
   - /services/brakes/ redirects to /brake-repair/.
   - A made-up address such as /xyz/ shows the site's 404 page.
   - The "Book an Appointment" button opens Shopgenie booking.

That's it. To update the site later, repeat steps 2-4 with the
new out.zip.
